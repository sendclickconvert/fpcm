Build a new Sunday School Registration page for the FPCM Astro site with a hidden server-side webhook.

1) CREATE `src/pages/sunday-school-registration.astro`

Follow the same design language as the existing `/contact` page. Import BaseLayout, PageHero, GetNotified, and CHURCH from `../data/site`.

Page structure:
- PageHero at the top: title "Sunday School Registration", subtitle "Register your child for the 2026 program year", image "/images/sunday-school-hero.jpg", size "lg".
- Triangle-pattern section with a short intro paragraph, then the form inside a card: `bg-white rounded-tl-[80px] rounded-br-[80px] p-6 md:p-10 max-w-4xl mx-auto`.
- Form action: `/api/sunday-school-register` (our own server endpoint — NOT the GHL URL). Method POST.
- Include hidden honeypot: `<input type="text" name="_hp" tabindex="-1" autocomplete="off" class="hidden" aria-hidden="true" />`
- Group fields into visual sections, each with an eyebrow line and `display-md text-navy mb-4` heading.

All inputs use the site's `.field !border-navy/30 w-full` class.

Section "About the Child":
- childFirstName (text, required, placeholder "Child's First Name *")

2) CREATE `src/pages/api/sunday-school-register.ts`

This is a server-side Astro API route. Follow the exact same pattern as `src/pages/api/submit-form.ts`.

- `export const prerender = false;`
- Handle POST
- Read FormData from the request
- Honeypot: if `_hp` field has any value, silently redirect to /thank-you (bot protection)
- Build payload with all form fields above plus:
    source: 'fpcmontgomery.org'
    endpoint: '/api/sunday-school-register'
    formType: 'sunday-school-registration'
    submittedAt: new Date().toISOString()
- HARDCODE the webhook URL directly in the file (not import.meta.env, not Replit Secrets). This URL must ONLY appear in this server-side file — never in the page template, never in the client-side HTML, never in any JS bundle:

const webhookUrl = 'https://services.leadconnectorhq.com/hooks/4aqSFaFFHXf5vD5GdZUj/webhook-trigger/sauHxcxxjfs6j0cbWO1T';

- Wrap the fetch to webhookUrl in try/catch — log errors server-side but never block the user
- Redirect to /thank-you on success

Because this file runs on the Node server (not the browser), the webhook URL is invisible to anyone viewing the page source, inspecting DevTools, or checking the network tab. The browser only ever sees requests to our own /api/sunday-school-register endpoint.
